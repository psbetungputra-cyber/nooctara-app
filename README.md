# Nooctara App

Nooctara adalah konsep social comfort & fun ecosystem: chat, vibe match, voice room, live room, mini games, wallet, reward, creator hub, dan profile prestige.

## RUN ini

```bash
npm install
npm run dev
```

Buka URL yang muncul dari Vite, biasanya:

```bash
http://localhost:5173
```

## Isi awal

- React + Vite foundation
- Dark premium Nooctara UI
- Home / Vibe Match / Chat / Room / Games / Wallet / Profile
- Logo concept board di `public/assets/nooctara-logo-board.png`
- Concept board di `public/assets/nooctara-concept-board.png`

## Catatan

Ini masih Foundation V1. Belum pakai Firebase, billing, payout, atau Play Store. Fokusnya kerangka UI dan flow produk dulu.
